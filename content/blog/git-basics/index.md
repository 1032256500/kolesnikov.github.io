## Что такое Git

Git — это распределённая система контроля версий,
которая позволяет отслеживать изменения в проекте.

## Основные возможности Git

- хранение истории изменений
- совместная работа
- работа с ветками
- откат изменений

## Основные команды

```bash
git init
git add .
git commit -m "message"
git push

```

## Вывод

- Git является важным инструментом современной разработки.
