# Что такое библиография

Библиография — это список источников,
используемых при написании научной работы.

# Основные задачи библиографии

- хранение источников;
- оформление ссылок;
- организация научных материалов;
- автоматическое создание списков литературы.

# Популярные библиографические сервисы

- Google Scholar
- ORCID
- Mendeley
- ResearchGate

# Преимущества использования библиографических систем

- экономия времени;
- удобное хранение статей;
- автоматическое оформление ссылок;
- поддержка научной деятельности.

# Заключение

Современные библиографические сервисы являются важной частью научной и образовательной деятельности.
